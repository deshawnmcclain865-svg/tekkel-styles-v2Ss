# Skin Menu (Fabric, Minecraft 1.21.11)

Taste **L** öffnet das Menü. Bilder (PNG) liegen in `.minecraft/config/skinmenu/images/`
oder werden einfach per Drag & Drop ins Menü gezogen. Mit `<` `>` wählst du ein Bild, `✕` setzt zurück.

Austauschbar: Inventar, Werkbank, Kiste, Ofen, Screen-Hintergrund, Hintergrund dieses Menüs.

Build: `./gradlew build` -> `build/libs/skinmenu-1.0.0.jar` in den mods-Ordner (+ Fabric API).
